Screenshot of the BugBountyTrainer C++ training application running C++20 | Cybersecurity Education | SQL | Docker BugBountyTrainer — Interactive Cybersecurity Training BugBountyTrainer is a menu-driven C++20 console application designed to help learners explore ethical hacking and secure software concepts in a simulated training environment. Users create researcher profiles, follow a structured learning path, solve challenges, practice SQL concepts, earn experience points, and save their progress. Major Features Researcher profiles, XP rewards, levels, and progressive module unlocks. Interactive training challenges and simulated hands-on labs. SQL Academy with guided modules and assessments. Isolated Docker-based SQL injection practice labs. Persistent save/load with validation and safeguards against duplicate rewards. Automated regression checks for core application behavior. Tools and Technologies C++20, Microsoft Visual Studio, Git, GitHub, GitHub Projects, PowerShell, SQL/SQLite, Docker, object-oriented programming, and software testing. Development Challenge One significant challenge was reliably restoring user progress as the application grew. Earlier save formats did not contain all newer training states, and invalid save data could cause inconsistent progress or repeat XP rewards. I expanded the versioned SaveManager, added validation for saved fields and counts, persisted SQL Academy completion and reward flags, and used regression tests to verify loading behavior and prevent duplicate rewards. What I Learned This project taught me to divide a larger program into cooperating classes, keep headers and source files organized, validate user input and saved data, test changes systematically, and document my development process. Using development branches, GitHub Issues, and pull requests helped me manage incremental improvements. The final project documentation reports 52 successful regression checks.
