My Projects

The following projects demonstrate my experience with C++ programming, cybersecurity education, software architecture, debugging, and collaborative development using Git and GitHub.

C++20 | Cybersecurity | SQL | Docker

BugBountyTrainer

BugBountyTrainer is an interactive cybersecurity education application developed using C++20. Inspired by hands-on cybersecurity training platforms, the application introduces users to ethical hacking, vulnerability research, SQL fundamentals, and practical security concepts. Users complete educational modules, participate in interactive challenges, earn experience points, and track their progress through an integrated researcher profile.

Key Features

  • Interactive cybersecurity learning modules and training challenges.
  • Researcher profiles with XP rewards and progression tracking.
  • Save and load functionality with persistent progress tracking.
  • SQL fundamentals and SQL injection training exercises.
  • Docker-based isolated cybersecurity practice environments.
  • Object-oriented architecture, input validation, and regression testing.

What I Learned

Developing BugBountyTrainer strengthened my understanding of object-oriented programming, software architecture, database integration, input validation, and debugging. I gained practical experience using Git branching, pull requests, regression testing, Docker containers, and professional documentation. The project also taught me the importance of incremental development, maintainable code, and designing applications around the needs of the user.
